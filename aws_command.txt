     Beklenen: "all checks passed", her sınıfta tam 6000 görüntü.

 4b) Platform belirlenimciliği — Fisher-Yates düzeltmesinin ASIL testi
     Mac'te üretilmiş referans repoda: reference/determinism_mac.csv
     (4 koşu: MNIST relu / tanh+relu / sigmoid, ve CIFAR-10 random layout)

rm -f /tmp/det_linux.csv
./main --act1 relu    --act2 relu --ratio 0   --layout interleave --hidden 12 --seed 1 \
       --epochs 2 --lr 0.003 --loss ce --dataset mnist   --quiet --data .. --out /tmp/det_linux.csv
./main --act1 tanh    --act2 relu --ratio 0.5 --layout interleave --hidden 12 --seed 1 \
       --epochs 2 --lr 0.003 --loss ce --dataset mnist   --quiet --data .. --out /tmp/det_linux.csv
./main --act1 sigmoid --act2 sigmoid --ratio 0 --layout interleave --hidden 12 --seed 1 \
       --epochs 2 --lr 0.03  --loss ce --dataset mnist   --quiet --data .. --out /tmp/det_linux.csv
./main --act1 tanh    --act2 relu --ratio 0.5 --layout random     --hidden 32 --seed 7 \
       --epochs 2 --lr 0.001 --loss ce --dataset cifar10 --quiet --data .. --out /tmp/det_linux.csv

python3 analysis/compare_rows.py /tmp/det_linux.csv reference/determinism_mac.csv

     Beklenen: "identical in all ... fields" x4, "0 mismatched".
     Mac'teki değerler: 92.24 / 91.48 / 90.97 (MNIST), 38.66 (CIFAR-10).

     ! DEĞİLSE DUR. Fisher-Yates çalışmıyor demektir; iki platformun verisi
       yine karıştırılamaz ve AWS koşusunun tek anlamı kalmaz.

 7b) KOŞU SIRASINDA YEDEK + MAC'İ UYUTMAMA  (spot kullanıyorsan şart)

 SIRA ÖNEMLİ.  Yedek döngüsü, sweep ZATEN ÇALIŞIRKEN başlatılır — önce değil.

   Terminal 3 (Mac)  adım 7b  aşağıdaki caffeinate komutu           <-- EN SON

 Mac'te, YENİ bir terminal penceresinde:

   caffeinate -is bash -c '
     while true; do
       rsync -az -e "ssh -i ~/.ssh/sweep-key.pem" \
         ubuntu@<PUBLIC_IP>:~/article/version5/results_aws/ \
         ~/Desktop/article/version5/results_aws/
       sleep 1800
     done'

 caffeinate bayrakları:
   -i   boşta kalma (idle) uykusunu engeller
   -s   sistem uykusunu engeller — YALNIZCA prize takılıyken geçerli
   Etki, sardığı komut bitene kadar sürer.  Ctrl+C -> döngü durur, Mac normale
   döner.  Ayrı bir "uyuma modu" açıp kapatmıyorsun, komutla birlikte yaşıyor.

 ! KAPAK AÇIK KALMALI.  caffeinate, MacBook'un kapağı kapatılınca devreye giren
   uykuyu engellemez.  Gece boyunca: şarja tak, kapağı açık bırak.  Ekranın
   sönmesi sorun değil (-d vermedik, zaten sönsün).

 ! Terminal penceresini kapatırsan döngü ölür.  Pencereyi açık bırak.

 Kapağı kapatmak zorundaysan iki seçenek:
   a) Yedeği makinenin kendisine yaptır  -> 7c (S3).  En temizi.
   b) sudo pmset -b disablesleep 1       # kapak kapalıyken de uyumaz
      İş biter bitmez MUTLAKA geri al:  sudo pmset -b disablesleep 0
      (unutursan Mac bir daha hiç uyumaz, pil erir)

 Spot kesilse bile o ana kadarki her koşu elinde kalır; instance geri gelince
 aynı komut kaldığı yerden devam eder.

 ! Persistent + Stop seçtiysen, kesinti sonrası instance'ın PUBLIC IP'si
   DEĞİŞİR.  Döngü o andan itibaren eski IP'ye bağlanmaya çalışıp boşa döner —
   hata vermez, sessizce yedek almaz.  Çözüm:
     - Önceden Elastic IP bağla (EC2 -> Esnek IP'ler -> ayır -> ilişkilendir),
       IP sabit kalır, hiçbir komutu değiştirmen gerekmez; ya da
     - Ctrl+C, konsoldan yeni IP'yi al, komutu yeniden başlat.
